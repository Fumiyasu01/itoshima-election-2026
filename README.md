# みんなの選挙 糸島

2026年2月 糸島市議会議員選挙の候補者アンケート回答を掲載するウェブサイト

## URL

https://minnano-senkyo-itoshima.com

## 概要

糸島市議会議員選挙の立候補予定者にアンケートを実施し、回答内容を市民に分かりやすく公開するためのサイトです。有権者が候補者の政策や考え方を比較検討できることを目的としています。

## 機能

### 候補者一覧
- カード形式で候補者を表示
- 政党/会派でのフィルタリング
- 各候補者の基本情報とスタンスを一覧表示

### スタンス表示
4つの政策軸について、候補者のスタンスをビジュアルで表示:
- 観光開発 vs 地場産業支援
- 大型開発 vs 生活基盤
- 高齢者福祉 vs 子育て支援
- 市長との関係（協調 vs 独立）

### 候補者比較機能
- 最大3名の候補者を並べて比較
- スタンス、政策、メッセージを横並びで確認可能

### 詳細モーダル
- 候補者カードをクリックで詳細情報を表示
- 長文回答は「続きを読む」で展開

### レスポンシブデザイン
- PC、タブレット、スマートフォンに対応

## 技術構成

- **形式**: 静的HTML（単一ファイル）
- **スタイリング**: CSS（インライン、CSS変数使用）
- **インタラクション**: Vanilla JavaScript
- **ホスティング**: GitHub Pages
- **ドメイン**: お名前.com で取得、GitHub Pagesに設定

## 候補者データの更新方法

`index.html` 内の `candidates` 配列を編集:

```javascript
const candidates = [
  {
    id: 1,
    name: "候補者名",
    party: "所属政党",
    photo: "picture/候補者名.png",  // 写真がない場合は空文字
    hashtags: "#タグ1 #タグ2",
    spot: "推しスポット回答",
    tenBillion: "10億円の使い道回答",
    stances: {
      tourism: 3,      // 1-5（1:地場産業支援寄り、5:観光開発寄り）
      development: 3,  // 1-5（1:生活基盤寄り、5:大型開発寄り）
      generation: 3,   // 1-5（1:子育て支援寄り、5:高齢者福祉寄り）
      leadership: 3    // 1-5（1:独立寄り、5:市長と協調寄り）
    },
    stanceNote: "",    // スタンスの補足説明（任意）
    nuclear: "原発対応回答",
    issue: "取り組みたい課題回答",
    vision: "糸島の将来像回答",
    message: "市民へのメッセージ回答"
  },
  // ...
];
```

## 運営情報

- **代表**: 松田一葉（マツダカズハ）
- **方針**: 中立・非営利・非党派
- **目的**: 選挙運動ではなく、情報提供活動

## 掲載方針

- 立候補者全員に平等にアンケートを配布
- 回答いただいた候補者のみを掲載
- 掲載順は回答受付順
- 原文を尊重し、編集は行いません

## ライセンス
